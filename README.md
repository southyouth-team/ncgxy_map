# 南昌工学院三维校园地图

基于 Vue 3 + Vite + Three.js + JavaScript 构建的模块化三维校园地图工程。

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm 10+

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 当前版本

当前提交为工程基础版本，包含程序化校园场景、建筑/道路/绿化基础资产，以及三种相机交互模式：

- 上帝视角：俯视、平移、缩放
- 第三人称：跟随观察目标，拖拽环绕、滚轮缩放、键盘移动
- 第一人称：点击进入鼠标视角，WASD/方向键移动，Shift 加速，Esc 释放鼠标

校园建筑目前使用程序化占位模型，后续可按实测校园平面数据、建筑照片和 GLB 模型逐步替换。不要将当前程序化布局当作精确测绘成果。
