# 本地打开二维地图编辑页

当前二维编辑器入口已接入应用主界面。

## 启动

```bash
npm install
npm run dev
```

浏览器访问：

```text
http://localhost:5173/?view=editor
```

也可以先打开应用首页，再点击导航栏的“二维搭建”。编辑器右上角的“切换三维视图”会返回现有 Three.js 校园浏览场景。

## 当前能力边界

- 二维画布支持地面/道路/水域瓦片绘制、图层切换、装饰对象放置、缩放。
- “导出草稿”会下载 JSON 文件；目前没有保存到服务端。
- 返回三维视图目前是返回现有三维校园浏览场景，不代表二维瓦片已经转换成三维地形。
- 真正的二维瓦片持久化与三维瓦片渲染适配仍是后续开发项。
