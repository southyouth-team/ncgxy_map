# 南昌工学院实地采集规范

## 目标

为全校每栋地上建筑建立可追溯的外形数据。首期只还原建筑外部体量，不采集室内结构。

## 采集前准备

1. 先在公开校园地图上给每栋建筑分配唯一编号（B001、B002……），编号一经分配不随楼名变化。
2. 准备手机、充电宝、卷尺或激光测距仪、记录表；可用手机 GNSS 记录粗略位置，但手机定位不能单独作为建筑角点的高精度测绘依据。
3. 确认校园拍摄与测量许可，遵守门禁和隐私要求；不拍摄人员面部、门禁系统、安防设施等无关信息。
4. 无人机仅在取得校方及相关空域许可后使用。

## 每栋建筑必采字段

- buildingId：建筑唯一编号
- name：官方名称；无法确认时留空
- footprint：建筑外轮廓角点，按顺时针或逆时针统一记录
- centroid：建筑中心点
- orientation：主立面朝向/建筑长轴方向
- length、width：外轮廓最大长宽，单位米
- floors：地上层数；不确定时记录估计值和置信度
- heightMeters：可测则记录；否则按层数估算并标注 estimated
- roofType：平屋顶、坡屋顶、复杂屋顶或 unknown
- facadeMaterial、facadeColor：可观察的主要外墙材质与颜色
- sourceRefs：公开地图、官网照片、现场照片的来源编号
- confidence：high / medium / low
- verifiedAt、verifiedBy：核验日期与采集人

## 拍摄要求

每栋建筑至少采集：
1. 东、南、西、北四个方向的立面照片（无法到达的一侧注明原因）。
2. 四个转角的斜向照片，用于判断建筑进深、转折和附属体量。
3. 主入口近景、屋顶轮廓或顶部构件照片。
4. 拍摄时记录建筑编号、方向、日期；照片文件名建议：B001_S_20261102_01.jpg。

## 测量与质量控制

- 先测建筑长宽，再测相邻建筑间距、道路宽度和建筑退界。
- 至少选择 3 个容易复测的固定控制点建立地图与现场坐标对应关系。
- 关键尺寸至少复测一次；两次结果差异明显时重新测量。
- 手机 GNSS 适合辅助定位，不应直接作为建筑边界精确坐标。
- 不确定的字段留空并降低 confidence，不允许凭印象填入精确数值。

## 交付检查

- 每栋楼有唯一编号。
- 每栋楼有可定位的 footprint 和来源记录。
- 建筑尺寸、层数与照片可互相核对。
- 未采集、无法进入或无法确认的内容明确标记，不用虚构数据补齐。
